# Minesweeper
Your favorite Minesweeper game with a cozy retro touch. Find the mines, place your flags, and try not to explode! 💥

---

## ✨ Features

- Classic Minesweeper gameplay
- Right-click to flag suspected mines
- Number indicators for adjacent mines
- Multiple difficulty levels
  - Beginner
  - Intermediate
  - Expert
- Custom retro pixel-art UI
- Responsive game interface
- Cozy, nostalgic visual theme

---

## 🛠️ Built With

- **Angular**
- **TypeScript**
- **SCSS**
- **HTML**
- **SVG / Pixel Art**

---

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/cute-minesweeper.git
```

Navigate into the project:

```bash
cd cute-minesweeper
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
ng serve
```

Open your browser at:

```text
http://localhost:4200
```
